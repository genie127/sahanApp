# 남은 작업 체크리스트

> 기준일: 2026-09-19
> 6대 기능(웹뷰/스플래시/탭/설정/오프라인/푸시)의 **코드 골격은 완성** 상태.
> 남은 작업은 ① 기능 구현 몇 개 ② 스타일 다듬기 ③ 외부 값/환경 연결 ④ 빌드·배포로 나뉜다.
> 소요시간은 1인 개발 기준 러프 추정치이며, 외부 값 대기(약관 URL 등)는 제외한 순수 작업시간이다.

## 진행 우선순위 제안

1. **A1·A2 (딥링크/알림)** — 심사 근거가 되는 핵심 네이티브 상호작용. 먼저 완성.

3. **B (스타일)** — HTML/CSS 시안 나오면 그 기반으로 앱 컴포넌트에 반영.
4. **D (빌드·출시)** — 위 완료 후 실기기 테스트 → 빌드 → 제출.
